# Unagikuma

<p align="center"><img src="docs/images/IMG_8128.jpeg" alt="Unagikuma" width="240"></p>

**Ещё один инструмент проверки доступности: u(ptime) + nagi(os) + kuma(Uptime Kuma).**

**Лучшее из двух миров:** один файл на одной машине работает сразу, а когда захочется большего — присоедините другие машины, и получится кластер. Та же программа, ничего не нужно переносить.

Простой мониторинг на вашем собственном сервере: узнавайте сразу, когда сайт или сервер упал, без лишнего шума.

## Почему Unagikuma

- **Готов к работе примерно за 30 секунд.** Скачайте один файл, запустите его и откройте браузер.
- **Один файл, больше ничего ставить не нужно.** Работает в Linux, macOS, Windows и FreeBSD.
- **Следит за главным.** Сайты, серверы, порты, ping, DNS, SSL-сертификаты и срок действия доменов.
- **Оповещения туда, где вы уже есть.** Почта, Telegram, Slack, Discord, Feishu, DingTalk, WeCom, вебхуки и многое другое.
- **Страницы статуса**, чтобы ваши пользователи всегда были в курсе.
- **Легко переехать.** Перенесите мониторы из Uptime Kuma, Nagios, Checkmate или Gatus — в веб-интерфейсе или из командной строки.
- **Говорит на вашем языке.** Интерфейс доступен на 15 языках.

## Быстрый старт

**1.** Скачайте файл для своей системы со страницы [Releases](https://github.com/githubflyideas/unagikuma/releases/latest) и распакуйте его.

**2.** Запустите:

```sh
./unagikuma
```

В Windows запустите `unagikuma.exe`.

**3.** Откройте в браузере http://localhost:8077 и создайте учётную запись администратора.

**4.** Нажмите **Добавить монитор**, введите адрес сайта — готово.

> Открываете с другого компьютера? Перейдите на `http://<адрес-сервера>:8077` и введите **Токен настройки**, который программа показала при первом запуске.

## Одна машина, две машины, кластер

- **Одна машина:** запустите файл, добавьте монитор — готово. Ни базы данных, ни агентов.
- **Две машины:** вставьте код присоединения в **Настройки › Узлы**. Каждая машина проверяет и оповещает сама, так что падение одной не оставит вас без оповещений.
- **Кластер:** добавляйте сколько угодно площадок. Каждое оповещение показывает, что видит каждая площадка, — «лежит везде» или «лежит только отсюда».

![Упавший монитор и результат каждой площадки](docs/images/detail-sites.png)

## Без лавины оповещений

- **Упала ваша собственная сеть?** Одно сообщение о сети, а не по каждому монитору.
- **Лежит хост?** Его сервисы не сообщаются по одному.
- **Не больше трёх оповещений в минуту на канал;** остальное приходит одной сводкой. Восстановления уходят всегда сразу.

## Переезд с другого инструмента

В веб-интерфейсе откройте **Конфигурация › Импорт**, выберите Uptime Kuma, Nagios, Checkmate или Gatus, загрузите файл, проверьте предпросмотр и добавьте.

![Импорт из Uptime Kuma, Nagios, Checkmate или Gatus в веб-интерфейсе](docs/images/import.png)

Или из командной строки: сначала посмотрите с `--dry-run` (ничего не меняется), затем запустите ту же команду без него.

```sh
./unagikuma import kuma      --dry-run /path/to/kuma.db
./unagikuma import nagios    --dry-run /etc/nagios4/nagios.cfg
./unagikuma import checkmate --dry-run monitors.json
./unagikuma import gatus     --dry-run config.yaml
```

Checkmate и Gatus: переносятся HTTP-проверки. То, что нельзя перенести точно, показывается в списке и останавливает импорт, так что ничего не переносится наполовину.

## Забыли пароль?

На машине, где работает Unagikuma:

```sh
./unagikuma reset-password admin
```

Введите новый пароль дважды (он не отображается). Добавьте `--generate`, чтобы получить случайный пароль.
