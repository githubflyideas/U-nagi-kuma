# v2.0.0 — early-access release / 待验收版本

按维护者要求先发布供测试使用。本版本标记为 **Pre-release**，不是 Latest，不应直接替换生产实例。请在隔离数据目录中运行并预先备份；数据库包含新增迁移，不保证可直接降级。

## Included work

- UI themes, channel/on-call usability, report acceptance feedback and security improvements.
- Company (Tenant) / department (Workspace) isolation foundations, owned configuration and credentials, recurring checks and runtime status.
- Workspace-owned incidents and durable PROBLEM/RECOVERY notification delivery. Current supported routing is a single direct webhook/log destination; unsupported policy/transport combinations are rejected. Receiver acceptance followed by a crash before local acknowledgement can duplicate a delivery; this is not an exactly-once guarantee.
- Work-in-progress Workspace API/UI and import integration. Checkmate, Gatus, Uptime Kuma and Nagios department workflows and default/default onboarding still require integrated acceptance; this release does not claim them all complete.

## Verification boundary / 已知限制

- Current source compiles locally on Windows. Release archives are built from the tagged commit with genuine `v2.0.0` version metadata; cross-compilation is not target-platform runtime verification.
- Earlier CI and extracted Windows package results belonged to commit 811336c / v1.5.7-rc.1, not this integrated release. README screenshots are explicitly labelled v1.5.7-rc.1 and are not v2.0.0 acceptance evidence.
- The latest integrated full test suite is not green: notification/migration contract changes require test integration, and interrupted Workspace UI/import work has not completed final acceptance.
- Three independent final product scenarios, previous-version upgrade acceptance, platform-specific extracted-package acceptance and Windows SCM acceptance remain outstanding.
- Release artifacts have checksums, but build/checksum success must not be described as full product verification. Follow-up fixes will use new version tags rather than silently replacing this release's binaries.

Use a fresh isolated data directory. Do not connect test notification routes to real recipients. Please report issues with the platform, version and sanitized reproduction steps; never include credentials or production databases.
